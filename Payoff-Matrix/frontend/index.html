How to read it

One player updates per step. The animation shows the probability of each state, rather than a single random path.

Blue arrows are P1 moves; purple arrows are P2 moves. Staying in place has no arrow.

Examples replace the matrix. Random game also replaces turn chances, rules, and damping. Resize keeps overlapping cells.

First best breaks ties by action order. Random among best splits ties. Random among improvements stays put if nothing is better.
